# Guia de Prompts: Variantes da Logo Zeppelin

Este guia serve para gerar novas variantes da mesma logo da Zeppelin para nichos diferentes, mantendo a identidade visual original.

## Objetivo

Criar variações da logo do dirigível Zeppelin para perfis, campanhas ou nichos específicos, adicionando apenas um pequeno símbolo relacionado ao mercado atendido.

Exemplos de nichos:

- Barbearia
- Delivery
- Imobiliária
- Agência de veículos
- Restaurante
- Clínica
- Academia
- Pet shop
- Loja de roupas
- Mercado/mercearia

## Padrão Visual Obrigatório

Toda variante deve seguir exatamente este padrão:

- Logo branca.
- Fundo preto ou charcoal escuro sólido.
- Formato quadrado, ideal para foto de perfil do Instagram.
- Dirigível Zeppelin centralizado.
- Estilo flat, limpo e vetorial.
- Alto contraste.
- Sem texto.
- Sem nome de marca.
- Sem slogans.
- Sem marca d'água.
- Sem ícones grandes demais.
- Sem mudar o formato principal do dirigível.

## Travas Contra Erros

Sempre incluir estas restrições no prompt:

```text
O fundo deve ser um quadrado sólido preto/dark charcoal.
Não usar fundo transparente.
Não usar aparência de PNG recortado.
Não usar borda irregular.
Não usar glow, halo, fumaça, sombra ou vinheta.
Não criar sticker.
Não alterar a proporção original do dirigível.
Não transformar a logo em outro objeto.
```

## Estrutura Ideal da Variante

A melhor forma de criar uma variante é adicionar o símbolo do nicho em um destes lugares:

1. Dentro da gôndola/cabine do dirigível.
2. Abaixo do dirigível, como um detalhe pequeno.
3. Integrado ao traço inferior da logo.
4. Como símbolo minimalista próximo da cabine.

Para manter a identidade mais premium, prefira símbolos pequenos dentro da gôndola.

Para deixar o nicho mais óbvio, use o símbolo abaixo do dirigível.

## Prompt Base

Use este prompt como base e troque apenas o nicho e o símbolo:

```text
Use case: logo-brand
Asset type: Instagram profile logo concept for a [NICHO] websites brand extension

Primary request:
Edit the provided Zeppelin blimp logo by adding a simple [SIMBOLO_DO_NICHO] reference for [NICHO], while preserving the original white blimp silhouette and dark background.

Input images:
Image 1 is the edit target and strict visual reference.

Style/medium:
Clean vector-friendly monochrome logo, flat white icon, same exact visual style as the reference image.

Composition/framing:
Centered square composition, same angled blimp orientation, same scale and spacing as the reference. Add only a tiny [SIMBOLO_DO_NICHO] symbol [LOCAL_DO_SIMBOLO], subtle and compact.

Color palette:
Solid dark charcoal/black background and white logo only.

Constraints:
The background must be a full solid black/dark charcoal square, no transparent background, no cutout edge, no glow, no soft halo, no irregular vignette, no gray blob. Preserve the original Zeppelin identity and proportions as much as possible. No text, no brand names, no watermark.

Avoid:
Transparent PNG look, isolated sticker look, smoky background, gradients, shadows, glow, cropped logo, badge layout, large icon, changing the blimp proportions significantly.
```

## Versão Mais Fiel à Logo Original

Use quando quiser uma submarca discreta e premium:

```text
Create a very minimal [NICHO]-themed version of the provided Zeppelin blimp logo, using only a tiny [SIMBOLO_DO_NICHO] cue while keeping the original logo almost unchanged.

Place the tiny symbol inside the cabin/gondola area, subtle and compact.

Keep the full solid black/dark charcoal square background and the white logo only. No transparent background, no glow, no shadows, no sticker look, no irregular cutout.
```

## Versão Mais Óbvia Para o Nicho

Use quando quiser que a pessoa entenda o nicho de primeira:

```text
Edit the provided Zeppelin blimp logo by adding a clear but simple [SIMBOLO_DO_NICHO] reference beneath the blimp near the cabin.

The symbol should be small, flat, white, and integrated with the logo, but readable at Instagram profile size.

Keep the original Zeppelin blimp identity clearly recognizable. Solid black/dark charcoal square background only. No text, no watermark, no transparent PNG look.
```

## Versão Integrada ao Traço Inferior

Use quando quiser uma solução mais criativa:

```text
Edit the provided Zeppelin blimp logo so the existing lower swoosh or underside becomes a subtle [NICHO] cue.

Preserve the blimp silhouette and stripe structure. The added reference should feel integrated into the original logo, not pasted on.

Keep a solid dark charcoal/black square background and white logo only. No transparent background, no glow, no gradients, no sticker effect.
```

## Exemplos Prontos

### Barbearia

```text
Edit the provided Zeppelin blimp logo by adding a simple moustache reference for a barber shop niche.

Keep the blimp shape, white logo, and solid dark charcoal square background. Add a small curled moustache beneath the cabin, balanced with the blimp.

No text, no barber pole, no scissors, no gradients, no transparent background, no glow, no sticker look.
```

### Delivery

```text
Edit the provided Zeppelin blimp logo by adding a simple delivery reference using a package, location pin, or speed line.

Keep the original blimp silhouette immediately recognizable. Use a solid black/dark charcoal square background and white logo only.

No trucks, no scooters, no food-specific object, no text, no transparent PNG look, no glow, no irregular cutout.
```

### Imobiliária

```text
Edit the provided Zeppelin blimp logo by adding a simple real estate cue such as a tiny house, roof, building, key, or window grid.

Place the symbol inside the cabin/gondola area for a premium look, or beneath the cabin for a clearer niche read.

Keep the background solid black/dark charcoal and the logo white. No text, no badge layout, no detailed skyline, no transparent background.
```

### Agência de Veículos

```text
Edit the provided Zeppelin blimp logo by adding a simple automotive cue such as a tiny steering wheel, car silhouette, wheel, or road line.

For the cleanest version, place a small steering wheel inside the cabin/gondola area.

Keep the original Zeppelin identity, solid black/dark charcoal square background, and white logo only. No car brand logos, no racing flag, no transparent PNG look, no glow, no sticker effect.
```

## Checklist Antes de Aprovar

Antes de considerar uma variante boa, verificar:

- A logo ainda parece a Zeppelin?
- O fundo está preto sólido?
- A logo está branca?
- O símbolo do nicho está pequeno o suficiente?
- A imagem funciona como foto de perfil pequena?
- Não parece sticker/PNG recortado?
- Não tem brilho, fumaça, sombra ou vinheta estranha?
- Não tem texto ou marca d'água?
- O nicho é reconhecível sem destruir a identidade?

## Recomendação de Direção

Para uma identidade visual mais profissional, usar preferencialmente:

```text
Símbolo pequeno dentro da gôndola + fundo preto sólido + logo branca.
```

Para campanhas mais óbvias e comerciais:

```text
Símbolo pequeno abaixo do dirigível + fundo preto sólido + logo branca.
```
